ภาพแนวตั้ง 9:16

สร้างภาพแนวตั้งแยกจากภาพหลัก จัดวางเองได้แบบลากวาง เช่น เกมด้านบน กล้องด้านล่าง ส่งไป TikTok หรือ YouTube แนวตั้ง (ไลฟ์คู่แนวนอน+แนวตั้งบน YouTube ได้)

แชทรวมทุกช่องทาง

รวมแชท YouTube, Twitch และ Kick ไว้ที่เดียว เลือกได้ว่าจะให้แชทช่องไหนขึ้นจอ พร้อมแชทบนจอแบบสวยๆ สำหรับใส่ในไลฟ์

🔊

อ่านแชทเป็นเสียงภาษาไทย

👁

จำนวนผู้ชมบนจอ

แสดงคนดูแยกแต่ละช่องทางพร้อมยอดรวม (YouTube, TikTok, Twitch, Kick) เลือกได้ว่าจะโชว์ช่องไหน

🎨

ธีมและกรอบกล้อง

ธีมสำเร็จรูป นีออนเกมมิ่ง มินิมอล พาสเทล หรือสีแบรนด์ของคุณเอง กรอบกล้องมุมโค้ง/วงกลม ขอบไล่สี และแสงเรือง เปลี่ยนธีมแล้วทุกอย่างเปลี่ยนตาม

🏷

ป้ายและฉากสำเร็จรูป

  • ป้าย LIVE พร้อมเวลาที่ไลฟ์
  • ป้ายชื่อ และข้อความวิ่ง
  • ฉาก "เริ่มเร็วๆ นี้" พร้อมนับถอยหลัง, "พักเบรก", "จบไลฟ์"
✨

แต่งหน้ากล้องแบบ AI

ผิวเนียน หน้าใส ปรับสี ฟิลเตอร์สำเร็จรูป และ AI ตามหน้าอัตโนมัติ (หน้าเรียว ตาโต) ประมวลผลในเครื่อง ไม่ส่งภาพออกไปไหน

📲

สะท้อนหน้าจอมือถือ

เอาจอ Android (สาย USB) หรือ iPhone/iPad (AirPlay) ขึ้นไลฟ์ กดปุ่มเดียวใส่ลงฉากหรือภาพแนวตั้ง เหมาะกับเกมมือถือ

✂️

คลิปไฮไลต์แนวตั้ง

กดปุ่มหรือคีย์ลัดตอนมีจังหวะเด็ด ได้คลิปแนวตั้งทันที หรือเลือกตัดจากไลฟ์ทั้งไลฟ์หลังจบ ระบบเรียงช่วงที่แชทคึกคักที่สุดไว้ให้ พร้อมคิดชื่อคลิป รายละเอียด และแฮชแท็กให้ ถามก่อนโพสต์ทุกครั้ง

📊

สถิติไลฟ์

เก็บคนดูและแชทรายนาทีของทุกไลฟ์ ดูกราฟย้อนหลัง และสรุปว่าไลฟ์เวลาไหน ยาวแค่ไหน ชื่อแบบไหนคนดูเยอะสุด

🔔

แจ้งเตือนเมื่อสัญญาณหลุด

ถ้าช่องไหนหลุดหรือกำลังต่อใหม่ จะมีแจ้งเตือนบนจอ เสียงเตือน และไอคอน OBS กะพริบที่แถบงาน รู้ทันทีไม่ต้องคอยเช็ค

🎚

เสียงและไมค์

เลือก Track เสียงแยกแต่ละปลายทาง และเตือนเมื่อไมค์ไม่ได้ออกไลฟ์ จะไม่ไลฟ์ไปเงียบๆ โดยไม่รู้ตัว

⌨️

คีย์ลัดและสรุปสด

ตั้งคีย์ลัดเริ่ม/หยุดแต่ละช่อง หรือเก็บไฮไลต์ แถบสรุปบอกเวลาไลฟ์ ความเร็วอัปโหลด เฟรมหลุด และยอดคนดู

🔒

เก็บ key อย่างปลอดภัย

Stream key และ API key ถูกเข้ารหัสด้วยระบบของ Windows ไม่เก็บเป็นข้อความธรรมดา

ช่องทางที่ตั้งค่าไว้ให้แล้ว

เลือกจากรายการแล้วใส่ stream key ได้เลย หรือใส่ RTMP เองสำหรับช่องทางอื่น

วิธีติดตั้ง

ใช้เวลาไม่ถึง 1 นาที

  1. ติดตั้ง OBS Studio เวอร์ชัน 31 ขึ้นไป (จาก obsproject.com หรือ Steam) ถ้ามีแล้วข้ามได้
  2. ปิด OBS แล้ว ดาวน์โหลด Yodstream และดับเบิลคลิกไฟล์เพื่อติดตั้ง
  3. ถ้า Windows ขึ้นว่า "Windows protected your PC" ให้กด More info → Run anyway (ไฟล์ยังไม่มีลายเซ็นดิจิทัล)
  4. เปิด OBS แล้วไปที่เมนู Docks จะเห็นหน้าต่าง Yodstream, Vertical, Chat, Camera, Mirror และธีม ลากวางตรงไหนก็ได้
  5. กด + เพิ่มปลายทาง เลือกแพลตฟอร์ม ใส่ stream key แล้วกด เริ่มทั้งหมด ได้เลย

คำถามที่พบบ่อย

ใช้ฟรีไหม?

ใช้ได้ฟรีทุกฟีเจอร์ในเวอร์ชันนี้

ทำไม Windows เตือนตอนติดตั้ง?

เพราะไฟล์ยังไม่ได้เซ็นด้วยใบรับรองผู้พัฒนา กด More info → Run anyway ได้ ตรวจสอบไฟล์ได้จากค่า SHA-256 ด้านบน

ค่าที่ตั้งไว้ย้ายไปเครื่องอื่นได้ไหม?

ต้องตั้งใหม่ในเครื่องใหม่ โดยเฉพาะ stream key ที่ถูกเข้ารหัสผูกกับบัญชี Windows ของเครื่องเดิมเพื่อความปลอดภัย

ใช้กับ Mac ได้ไหม?

ตอนนี้ไฟล์ติดตั้งมีเฉพาะ Windows

ภาพจากกล้องถูกส่งไปที่ไหนไหม?

ไม่ การแต่งหน้าและ AI ตามหน้าทำงานในเครื่องทั้งหมด

ต้องเปิดเว็บไหนตอนไลฟ์ไหม?

ไม่ต้อง ทุกอย่างอยู่ใน OBS แชทบนจอและป้ายต่างๆ ใส่เป็น Browser Source ให้อัตโนมัติ
